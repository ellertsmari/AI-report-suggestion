# AI report suggestion

A proposal for how AI use is assessed in The Sustainable Island 2027, an Erasmus+ project between I.E.S. El Rincón (Las Palmas), Tækniskólinn (Reykjavík) and TECHCOLLEGE (Aalborg). It also suggests replacing the presentation on 21 January with group visits by teacher pairs. Prepared for the teachers' meeting on 2 October 2026.

It builds on the AI Use Policy Addendum drafted by Heinz K (TECHCOLLEGE) in May 2026.

- **Presentation:** https://ellertsmari.github.io/AI-report-suggestion/
- **Policy text (v2):** [AI-policy.md](AI-policy.md)
